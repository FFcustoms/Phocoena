# Known Issues

Current release: **Phocoena v0.1.27**

Phocoena is experimental and compatibility varies by game.

## Game Compatibility

Some GameCube games may:

- Fail to boot
- Need another launch attempt
- Crash during loading or gameplay
- Run below full speed
- Stutter or briefly pause

## Graphics

Possible issues include:

- Missing or incorrect textures
- Flickering
- Missing effects
- Rendering corruption
- Shader-related pauses

Phocoena currently uses Vulkan through NXVK.

## Audio

Audio is still experimental.

Some games may have missing, incorrect or poorly timed audio.

## Wii

Wii emulation is not currently considered working or supported.

The current tester program is focused on GameCube.

## Input And UI

The Switch frontend is intentionally simpler than desktop Dolphin.

Not all desktop Dolphin controller, configuration or debugging features are available yet.

## Reporting Problems

Please include:

- Game title
- What happened
- Whether it is repeatable
- The newest `UNSENT_Phocoena-Support-*.zip`

See [SWITCH_TESTING.md](SWITCH_TESTING.md) for testing instructions.
