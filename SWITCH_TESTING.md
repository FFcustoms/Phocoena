# Testing Phocoena

Current tester build: **Phocoena v0.1.27**

Please leave the default settings unchanged unless specifically asked to change them.

## Test

Please test at least **5 GameCube games** if possible.

For each game:

1. Launch the game.
2. Get into actual gameplay.
3. Play for about 10 minutes when practical.
4. Note crashes, graphics problems, audio problems, slowdown, stutter or anything unusual.
5. Return to Phocoena before launching the next game.

## When Finished

Open:

**About / Diagnostics**

Press:

**X - Generate support bundle**

The reports are stored in:

`SD:/switch/Phocoena/diagnostics/bundles/`

Send back the newest ZIP beginning with:

`UNSENT_`

Example:

`UNSENT_Phocoena-Support-1234567890.zip`

Older bundles that have been superseded are marked:

`SENT_`

If Phocoena reports:

`no new game sessions to bundle`

nothing new needs to be sent.

## If Something Crashes

Relaunch Phocoena if possible and generate a support bundle.

Please include:

- Game name
- What happened
- Roughly where it happened
- Whether it happened more than once
- The newest `UNSENT_` ZIP

Do not delete the diagnostics folder after a crash.

## Current Scope

GameCube is the current testing target.

Wii testing is not currently supported.

Use only your own legally obtained game dumps.
